Del papel escaneado
al texto que podés leer, copiar y traducir.

Subí un libro, un apunte o un documento. Las páginas que ya tienen texto se leen al instante; las escaneadas pasan por OCR con Gemini. Todo queda ordenado en títulos, párrafos, listas, tablas y notas.

  • Página por página. Detecta qué páginas tienen texto y cuáles son imágenes, y usa OCR solo donde hace falta.
  • Libros enteros. Procesa por tramos, muestra el avance y, si algo falla, retoma desde donde quedó.
  • Privado. El PDF y tu API key quedan en este navegador; solo viajan a Google para el OCR.

    Tus API keys

    Gemini

    La app llama al modelo directamente desde tu navegador. La key se guarda solo en este dispositivo. Conseguila gratis en Google AI Studio → Create API key.

    Con la key gratuita, Google puede usar el contenido enviado para mejorar sus productos. Para documentos confidenciales usá una key con facturación activada.

    Claude (opcional)

    Para usar los modelos de Claude, elegilos en Avanzado → Modelo. La key se crea en la Consola de Claude → API keys. El uso de la API se cobra aparte de la suscripción de Claude (los planes Max, Ultra y Team traen créditos mensuales).

    Con Claude conviene apagar «Recortar figuras»: ubica los recuadros de las figuras con menos precisión que Gemini.

    Historial

    Los documentos quedan guardados en este navegador, con el PDF, para releerlos o terminar de procesarlos.
